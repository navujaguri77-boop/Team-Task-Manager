# FlowDesk Quick Start Guide

## 🎯 What You Have

A **complete, production-ready Team Task Manager** application with:
- Full-stack web app (React frontend, FastAPI backend)
- Real-time task management with Kanban board
- Team collaboration features
- Role-based access control
- Beautiful, responsive UI
- Comprehensive testing suite
- Production deployment configuration

## 🚀 Start in 5 Minutes

### 1. Backend Setup

```bash
# Navigate to backend
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Copy environment file
cp .env.example .env

# Edit .env - set PostgreSQL connection
# DATABASE_URL=postgresql://user:password@localhost:5432/flowdesk

# Run the API server
python main.py
```

✅ Backend runs on: http://localhost:8000
📚 API Docs: http://localhost:8000/docs

### 2. Frontend Setup

```bash
# In a new terminal, navigate to frontend
cd frontend

# Install dependencies
npm install

# Copy environment file
cp .env.local.example .env.local

# Start development server
npm run dev
```

✅ Frontend runs on: http://localhost:3000

### 3. Create Your Account

1. Open http://localhost:3000
2. Click "Sign Up"
3. Create account with:
   - Name: Your Name
   - Email: your@email.com
   - Password: Must be 8+ chars, include uppercase and number (e.g., `MyPassword123`)
4. Click "Sign Up"
5. You're logged in! 🎉

## 📊 Try These Features

### Dashboard
- View your project count, tasks, and progress
- See recent tasks and project status

### Create a Project
1. Go to **Projects** page
2. Click **"New Project"** (top right)
3. Fill in name, description, choose status
4. Click **"Create Project"**
5. Click on the project card to view details

### Manage Tasks
1. In project detail, click **"Add Task"**
2. Fill task details (title, priority, assignee, due date)
3. Tasks appear in Kanban board columns
4. Drag between columns to update status
5. Or use the status dropdown

### Assign Teammates
1. Go to **Team** (Admin only)
2. You can change roles and manage members

### Dark Mode
Click the moon icon in the header to toggle dark theme!

## 🗄️ Database

PostgreSQL is required. Install locally:

**macOS:**
```bash
brew install postgresql@15
brew services start postgresql@15
createuser user
createdb -U user flowdesk
```

**Linux:**
```bash
sudo apt install postgresql
sudo -u postgres createuser user
sudo -u postgres createdb -O user flowdesk
```

**Windows:**
Download: https://www.postgresql.org/download/windows/

Then set in `.env`:
```
DATABASE_URL=postgresql://user:password@localhost:5432/flowdesk
```

## 🚀 Deploy to Production (Railway)

### Prerequisites
- GitHub account
- Railway account (free at https://railway.app)
- Push code to GitHub

### Steps

1. **Create Railway project**
   - Go to https://railway.app
   - Click "New Project" → "Deploy from GitHub"

2. **Connect repo**
   - Select your FlowDesk repository
   - Railway auto-detects from `railway.toml`

3. **Set environment variables**
   In Railway dashboard, add:
   ```
   DATABASE_URL=<auto-generated by Railway>
   JWT_SECRET=<generate strong random key>
   JWT_REFRESH_SECRET=<generate strong random key>
   ENVIRONMENT=production
   FRONTEND_URL=https://<your-domain>.railway.app
   ```

4. **Deploy**
   - Push to main branch
   - Railway auto-deploys!
   - Your app is live at: `https://<your-app>.railway.app`

### Troubleshooting

**"Connection refused" error:**
- Ensure PostgreSQL is running
- Check DATABASE_URL in .env

**"Port 3000 already in use":**
```bash
# Find and kill process
lsof -ti:3000 | xargs kill -9
```

**"Auth token expired":**
- Refresh tokens auto-renew
- If stuck, clear localStorage: `localStorage.clear()` in browser console

**API not responding:**
- Check backend is running: `python main.py`
- Verify NEXT_PUBLIC_API_URL in frontend `.env.local`
